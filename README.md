# Distributed E-Commerce Microservices

## Project Overview

This project aims to build a scalable event-driven E-Commerce platform using a microservices architecture.

## Tech Stack

- Java 17+
- Spring Boot 3
- Spring Cloud
- Apache Kafka
- PostgreSQL
- MongoDB
- Docker
- Kubernetes

## Planned Microservices

- API Gateway
- Order Service
- Inventory Service
- Payment Service
- Notification Service

## Project Goals

- Build independent microservices
- Implement event-driven communication
- Ensure scalability and reliability
- Follow industry-standard development practices

## Team Workflow

- Individual branches for each member
- Regular GitHub commits
- Pull Request based collaboration
